# Tri-Vector Context

## Definition

The tri-vector is the minimal contextual signature used to frame content within the `commons-vector-v1` protocol.

## Coordinates

- tri_vector: `1a0de0b-f30c`
- spatial_vector: `7e34-88a8`
- rule_vector: `057e4f535abc`

## Interpretation

The tri-vector establishes a local contextual state. It does not replace a content identifier, but it gives the content a situational frame.

The formula is:

`content + context + provenance + dictionary = instrument`

## Rule

Repository folders are part of the context model. The content itself is not the entire meaning; the arrangement of files and folders contributes to its interpretive environment.
