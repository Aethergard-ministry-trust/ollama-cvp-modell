# Architecture

## Repository structure

- `protocol/` — protocol definitions and boundaries
- `dictionary/` — versioned dictionaries and vocabulary
- `genesis/` — initial protocol state and record
- `context/` — contextual and coordinate structures
- `provenance/` — provenance chain and schema
- `archive/` — living archive documentation
- `research/` — methodology and historical sources
- `art/` — artistic and philosophical framing
- `docs/` — project documentation
- `assets/` — images and supporting media

## Design principle

The technical protocol, semantic dictionary, and artistic framework are intentionally separated, but they are related and should be reviewed in context.
