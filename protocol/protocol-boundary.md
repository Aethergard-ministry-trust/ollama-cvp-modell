# Protocol Boundary

## Scope

The Commons Vector Protocol defines how records, content identifiers, dictionary meaning, and provenance relationships are represented and verified.

## Boundary

This repository includes:

- protocol definitions
- dictionary vocabulary
- contextual coordinates
- historical and research notes
- archival records
- artistic framing

This repository does not replace:

- statutory legal systems
- private key infrastructure for identity proofing
- institutional governance claims
- external registry records

## Principle

The protocol is defined by records and references, not by claims of authority alone.
